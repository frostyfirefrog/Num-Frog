# 🐸 Num Frog — Numpad Key Remapper

**Num Frog** is a Chrome extension that lets you remap numpad keys to custom keyboard inputs using a simple, interactive interface with a pixel-art-inspired purple-and-black theme.

Built to make everyday typing and coding more convenient! ⌨️

## 💡 Why I Built This

As a **first-year (FY) student learning C programming**, I noticed how frequently I needed to type special characters like `<`, `>`, `?`, `:`, `"`, `{`, and others.

On many keyboard layouts, these characters require pressing `Shift` along with another key. Constantly switching between keys can become irritating when coding.

That gave me an idea: **What if I could customize my numpad to make frequently used inputs easier to access?**

So, I built Num Frog!

My goal is to make keyboard customization more accessible for students, programmers, and anyone who wants a more personalized typing experience.

## ✨ Features

- ⌨️ **Custom Key Remapping** — Remap supported numpad keys to your preferred keyboard inputs.
- 👻 **Original Key Display** — View original key mappings alongside remapped keys.
- 🎨 **Pixel-Art UI** — A minimalist purple-and-black interface with a custom Num Frog logo.
- 🔄 **One-Click Reset** — Restore the default key mappings easily.
- 🔒 **Num Lock Protection** — Keep the Num Lock key protected from accidental remapping.
- 🟣 **Interactive Key States** — Visual feedback makes key selection and remapping easier to understand.

## 🚀 Installation

To install Num Frog locally in Google Chrome:

1. Download or clone this repository.
2. Extract the ZIP file if you downloaded the project as a ZIP.
3. Open Chrome and navigate to `chrome://extensions/`.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted project folder containing `manifest.json`.
7. Pin Num Frog to your toolbar and start exploring!

> **Note:** This describes loading the extension locally. Availability on the Chrome Web Store is separate.
